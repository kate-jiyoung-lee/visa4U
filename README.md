# LIRA — 의안 자동 검토 어시스턴트

> 입법, 다시 한 번 점검하는 AI 동료
>
> 경기도의회 법제과 AI 바이브 코딩 워크숍 출품작

---

## 1. 무엇인가요?

의원 발의안·조례안을 입력하면, 법제처 자치법규 입안 길라잡이 등 공식 기준에 따라 5가지 영역을 자동 점검하고 **출처가 명시된 검토의견서 초안**을 만들어 주는 도구입니다.

**5가지 검토 영역**
1. **인용 무결성 검증** — 인용된 법령이 지금도 유효한지
2. **법체계 적법성 검토** — 상위법 위반·사무 구분·권한 침해
3. **자치법규 정합성 검토** — 다른 조례 충돌·정비 필요성
4. **입법기술 점검** — 시행일·경과조치·적용례
5. **양성평등·차별·영향 통합 점검** — 차별적/일본식 용어 + 양성평등 + 약자 영향

## 2. 사용법

### 2.1 도구 열기

1. `src/index.html` 파일을 **더블클릭** 또는 브라우저에 끌어놓기
2. Edge, Chrome 등 어디서나 열림 (설치 불필요)

### 2.2 처음 설정

1. **AI 제공자 선택** — Claude(시연용) 또는 Gemini(무료 보급용)
2. **AI API 키 입력** — 아래 발급 가이드 참고
3. **국가법령정보센터 ID(OC) 입력** — 인용 법령 유효성 실시간 조회용 (선택, 미입력 시 정확도 ↓)

### 2.3 검토하기

1. 발의안 텍스트를 큰 입력창에 붙여넣기
2. "🔍 검토 시작" 클릭
3. 약 30초 후 결과 5단 구조로 출력

## 3. API 키 발급 가이드

### 3.1 Claude API 키 (Anthropic) — 시연용 권장

1. [https://console.anthropic.com](https://console.anthropic.com) 접속
2. 회원가입 (이메일 + 카드 등록)
3. 좌측 메뉴 → **API Keys** → **Create Key**
4. 키 복사 (sk-ant-... 로 시작)
5. **비용**: 의안 1건 검토 약 100~200원 (Sonnet 4.6 기준)
6. **신규 가입 시 $5 무료 크레딧** 제공

### 3.2 Gemini API 키 (Google) — 무료 보급용 ⭐

1. [https://aistudio.google.com](https://aistudio.google.com) 접속
2. Google 계정 로그인
3. **Get API key** → **Create API key in new project**
4. 키 복사 (AIza... 로 시작)
5. **비용**: **무료** (일 1,500요청)
6. **카드 등록 불필요**

### 3.3 국가법령정보센터 API ID (OC)

1. [https://open.law.go.kr](https://open.law.go.kr) 접속
2. 회원가입 후 신청
3. 발급받은 사용자 ID 사용

## 4. 현재 버전 (v0.2) — 상태

| 항목 | 상태 |
|---|---|
| ①번 인용 무결성 검증 | ✅ 실제 작동 (Claude/Gemini + 국가법령정보센터 API 시도) |
| ②번 법체계 적법성 검토 | ✅ 실제 작동 (사무 구분·상위법·법률유보·견제와 균형) |
| ③번 자치법규 정합성 검토 | ✅ 실제 작동 (충돌·정비·입법방식) |
| ④번 입법기술 점검 | ✅ 실제 작동 (시행일·경과조치·적용례·부칙) |
| ⑤번 양성평등·차별·영향 | ✅ 실제 작동 (차별적 용어·양성평등·약자 영향) |
| 법제처 자료 임베딩 (RAG) | 🔧 5.28 ~ 5.29 도입 (정확도 ↑↑) |
| 시스템 프롬프트 정교화 | 🔧 5.29 이후 |
| 실제 발의안 5건으로 검증 | 🔧 5.29 이후 |

### 기술적 한계
- API 키가 브라우저 메모리에만 보관 (페이지 새로고침 시 다시 입력 필요)
- 국가법령정보센터 API는 브라우저 CORS 제약 가능성 → 실패 시 AI가 단독 분석
- AI 응답이 항상 정확하지는 않음 → **최종 판단은 법제과 변호사 자문 필요**

## 7. 차별화 포인트

1. **법제처 자료 페이지까지 인용하는 AI** — AI 환각 방지, 검증 가능
2. **AI 모듈 교체 가능 구조** — Claude/Gemini/CLOVA 갈아끼우기 가능
3. **양성평등·차별 표현 점검 자동화** — 현행 검토의견서가 약한 영역 보강
4. **단일 HTML** — 설치 불필요, 의회 사내 보안 충돌 없음
5. **비용 0원 가능** — Gemini 무료 티어로 누구나 즉시 사용

## 8. 면책 및 사용 주의

> **본 점검 결과는 AI에 의한 1차 보조이며, 최종 판단은 입법조사관·법제과 변호사 자문이 필요합니다.**

- 출처가 명시되지 않은 결과는 신중히 검토
