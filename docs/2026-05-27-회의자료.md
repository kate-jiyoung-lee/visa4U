# LIRA 1차 회의 자료 (5.27 PM 2시)

> 법제과 팀 출품작 — 의안 자동 검토 어시스턴트

---

## 한 줄 소개

**LIRA** = 의원 발의안을 넣으면 **법제처 자치법규 입안 길라잡이 페이지까지 인용하면서** 5가지 검토를 자동으로 해주는 단일 HTML 도구.

---

## 5가지 검토 영역

| # | 영역 | 한 줄 설명 |
|---|---|---|
| ① | **인용 무결성 검증** | 인용된 법령이 지금도 유효한지 자동 체크 |
| ② | **법체계 적법성 검토** | 상위법 위반 + 사무 구분 + 권한 침해 점검 |
| ③ | **자치법규 정합성 검토** | 다른 조례와 충돌 + 정비 필요성 |
| ④ | **입법기술 점검** | 시행일·경과조치·적용례·부칙 |
| ⑤ | **양성평등·차별·영향 통합 점검** | 차별적/일본식 용어 + 양성평등 영향 + 약자/안전 |

---

## 출력 양식 — 5단 구조

```
○ 카테고리 — 항목명
▸ 발견: 안 제X조에서 ~
📜 관련 법령: 「○○법」 제X조 → 적합/부적합
📖 참고: 법제처, 『자치법규 입안 길라잡이』, 2022, p.XX
💭 판단: [근거 기반 추론]
💡 의견: ⚠ ~로 수정 제안
```

---

## 차별화 포인트 3가지

1. **출처 신뢰성** — 법제처 자료 페이지 번호까지 인용 (AI 환각 방지)
2. **AI 모듈 교체 가능** — Claude 시연 / Gemini 무료 보급
3. **양성평등·차별 표현 점검** — 현행 보고서가 약한 영역 보강

---

## 데이터·기술

- **단일 HTML** (CASA 패턴) — 설치 불필요, 사내 보안 충돌 없음
- **국가법령정보센터 API** — 인용 법령 유효성 실시간 확인 (API 키 발급 완료)
- **법제처 자료 임베딩 (RAG)** — 자치법규 입안 길라잡이 등 페이지별 chunk
- **Claude API or Gemini API** — AI 분석 (다중 지원)
